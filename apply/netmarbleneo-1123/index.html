타겟

대중교통을 자주 이용하거나 캐주얼 모바일 게임을 좋아하는 10~30대

포인트
  1. 망치의 시원한 타격감적을 자기장으로 날려보내어 킬을 함으로써 발생하는 도파민
  2. 한 판에 3~4분이 소요되는 스피디한 게임 진행출근길에도 부담 없이 즐길 수 있는 짧은 플레이타임

  4. 트로피 시스템과 스킨을 통한 BM브롤스타즈에서 차용하여 캐릭터별 트로피 목표와 캐릭터 스킨을 연계
  5. 다양한 콘텐츠 확장 가능성팀전, 뱀서라이크(개인/협동) 등 PVP·PVE로 확장이 가능

나는 악마가 밉다
영웅을 배치해 악마의 층을 돌파하는 도트 오토배틀

타겟

다키스트 던전·슬레이 더 스파이어류 로그라이트를 좋아하는 10~30대 모바일 유저

포인트
  1. 배치로 이기는 쾌감조작 없는 자동 전투, 승패를 가르는 배치와 빌드 (봇 실험: 고른 배치 완주율 43~50%, 무작위 22~25%)
  2. 돌아오지 않는 용병죽으면 사라지는 용병과 새로운 영입, 층마다 규칙을 비트는 악마
  3. 감지도로 쌓이는 긴장방을 고를수록 차오르는 감지도, 100을 넘으면 그 층의 악마와 결전
  4. 후회가 수요가 되는 BM용병을 잃은 직후 직전 방으로 되감는 「회중시계」 (가설)

01재미 검증

타겟과 재미, BM을 정한 아이디어로 아트 스타일 후보를 여러 개 만들어 고르고, 그 스타일로 메커닉 위주의 간단한 프로토타입을 만들어 한 사이클을 플레이한다. 기준을 넘으면 본격적인 제작에 착수한다.

02기획

사전 제작한 총괄 기획 기입본을 통해 상세 기획을 진행하고 사용할 AI 툴들을 선정한다. 아트 일관성과 같은 파트별 규칙들을 마크다운 파일을 통해 하네싱한 후, 에디터 없는 스크립팅 작업을 기반으로 데이터 테이블 형태로 최대한 가공한다.

03맵 · 아트

랜드마크를 잇게 지시하고 거리는 수치로 말한다. 생성 이미지는 게임 규격에 맞춰 다시 만든다.

04사운드

AI가 프롬프트를 쓰고, 사람이 검수한 뒤 생성한다. 후보를 들어 보고 고른다.

05콘텐츠 · BM

재미가 확인된 뒤에 스킬과 스테이지를 양산한다. BM은 프로토타입에서 정할 것만 적어 둔다.

06밸런스

LLM 없이 도는 봇 대전으로 수치 변경 전후를 잰다. 시뮬레이션을 통해 무인작업 검증을 진행하고 보고한다. 재미는 사람이 판단한다.

07최적화

고치기 전에 같은 조건에서 병목부터 잰다. 같은 조건의 값끼리만 비교한다.

08QA

자동 검사로 걸러 내고, 받은 결과는 다시 검사한다. 마지막 통과는 사람이 직접 플레이해 정한다.
